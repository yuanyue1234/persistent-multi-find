# 多词高亮 · 连续查找与批量编辑

Chrome / Edge 扩展，版本 **1.16.0**。把多个关键词存成规则，持续高亮，预览后替换或追加。

**[打开交互演示](https://asunny.top/persistent-multi-find/)** · **[下载插件 ZIP](https://github.com/yuanyue1234/persistent-multi-find/raw/refs/heads/main/downloads/persistent-multi-find-v1.16.0.zip)**

## 安装

1. 下载 ZIP 并解压到固定目录。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
4. 打开普通网页，点击扩展图标；快捷键为 `Ctrl+Shift+F`。

更新时在扩展管理页重新加载插件，**再刷新目标网页**。不要先卸载，以免丢失本地规则。

## 使用

顶部「工具」菜单集中提供导入 / 导出、读取素材、大小写和深色模式。搜索匹配词、替换文字及排除项；搜索后批量替换 / 追加只处理可见词条。排序支持最新在前、最早在前与拖动后的手动排序。

复制导出以方案名开头，普通词条不添加空排除标记，例如：

```text
# 镜头012 秦烈追击
黑马 | [20_资产_人物表_R23_C5_战马与护卫骑乘马.jpeg]
秦烈 | [17_资产_人物表_R07_C5_秦烈｜秦军校尉.jpeg]
```

默认勾选「全局」，导入导出所有项目与方案：`## 项目名` 分项目、`# 方案名` 分片段。导入按项目名和方案名合并，同关键词更新，不删除未列出的词条；遇到重名歧义会拒绝导入。取消全局后仅导出当前片段，导入也只接受一个方案并更新当前方案名。仅高亮和删除标记仍保留以便还原模式。切换范围自动刷新未编辑的导出文本，不覆盖已粘贴或编辑的内容。


- **项目与方案**：顶部下拉菜单切换项目，下方切换生成段方案；新方案从「方案1」开始编号。
- **替换**：输入目标文字；留空代表删除。单项与全部操作均先预览再确认。
- **追加**：保留匹配文字，在后面添加输入内容；留空不操作。
- **仅高亮**：收起词条的替换栏，该词条不参与替换或追加。
- **排除与正则**：排除特定完整文本，支持正则捕获组，例如 `$1`。方括号按钮只包裹一层，支持自定义包裹规则。
- **素材绑定**：读取当前生成段上方已有图片素材，再选择绑定版本；不猜测素材 ID，不自动选择服装状态。
- **撤回**：替换框支持 Ctrl+Z、Ctrl+Y / Ctrl+Shift+Z；网页「恢复上次」保留最近10次操作，刷新后清空，且不覆盖后续变动的正文。
- **布局**：深色 / 浅色、侧栏与独立窗口、拖动排序；颜色按感知色差分配，已有颜色保留。

项目、方案与设置保存在浏览器本地，无账号或云同步。浏览器内部页面、扩展商店等受限页面不可注入脚本；跨文本节点匹配及真实网站保存行为存在限制，先在测试内容中验证。

## 演示网页

仓库根目录 `index.html` 为说明与交互演示，复用扩展的 `rules.js`。支持高亮、替换、追加、排除、正则及预览后的应用与撤回；不会访问其他网页或上传输入。

本地预览：运行 `node tests/server.cjs`，打开 <http://127.0.0.1:8894/index.html>。演示无需安装依赖，自动测试需先安装开发依赖。

## 开发与验证

扩展使用原生 JavaScript，无构建步骤。运行 `pnpm install`，再运行 `pnpm test`（也可 `node --test tests/*.test.cjs`）。

- `popup.*` / `view.js` / `workspace.js`：弹窗、独立窗口、侧栏。
- `rules.js` / `materials.js` / `content.js`：匹配引擎、素材解析与页面操作。
- `palette.js` / `background.js`：共享配色、后台菜单。
- `tests/`：自动回归及浏览器模拟夹具。

模拟测试不能替代真实安装扩展、系统中文输入法及目标网站素材保存验证。
